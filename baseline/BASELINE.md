# Эталонные снимки

Снято с ЗАМОРОЖЕННЫХ экранов стенда, а не с живого приложения: снимок
приложения зависит от данных и времени (метка текущего часа в календаре,
«сегодня» в отчётах), и через час отличался бы сам собой.

* коммит стенда: `5fc08b9`
* экранов: 86
* вьюпорт: 1600x1000

Сверить текущий вид с этим эталоном:

```
python scripts/visual_baseline.py --check
```

Если правка меняет РАЗМЕТКУ, стенд пересобирается и эталон устаревает
законно — тогда он снимается заново (`--capture`), и эта запись меняется.
