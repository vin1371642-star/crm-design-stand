завода). Внешние картинки из случайной выдачи не используются. Для каждой картинки
указан источник, тема и статус (как есть / перерисовано).

Заменены примитивные matplotlib-схемы (устройство окна, профиль, стеклопакет,
фурнитура, монтажный узел) на реальные фото завода / фирменный каталог + одну
аккуратную схему монтажного шва. Без чужих логотипов-конкурентов и водяных знаков.
Все изображения читаемы на телефоне и ПК (ширина ~1200 px, кабинет масштабирует по
ширине экрана).
